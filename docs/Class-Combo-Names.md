# Class names for archetype combinations

On the Status screen, "Archetype" becomes "Class". A player with one archetype shows that archetype's name (e.g. *Class: Knight*). A player with two shows the combination's name (e.g. *Class: Paladin*). Every pair has three options: reply with the number and letter you want (e.g. `3A, 17C`), or give your own name.
